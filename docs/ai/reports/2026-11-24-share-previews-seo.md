## 1. Summary

The game now unfurls as a large, on-brand preview card when its link is shared. It also has
complete search metadata, app icons and a web manifest. The same setup was applied to all four
portfolio games, each with its own theme.

## 2. Completed Work

- [x] `apps/web/share-meta.ts`: a Vite plugin that derives share tags from `index.html`:
  - `og:*` with image size, type and alt text;
  - `twitter:card=summary_large_image`;
  - canonical;
  - robots with `max-image-preview:large`;
  - keywords;
  - JSON-LD `VideoGame` with the author.
  It also emits `robots.txt` and `sitemap.xml`.
- [x] Origin resolution: `SITE_URL`, then Netlify `URL` (only when `NETLIFY=true`), then
  `VERCEL_PROJECT_PRODUCTION_URL`. Without one, the build uses relative URLs and warns.
- [x] `index.html` changes:
  - an SEO title and a description of 150 characters or fewer;
  - PNG and apple-touch icons;
  - a manifest link;
  - `application-name` and `apple-mobile-web-app-title`;
  - a `<noscript>` summary.
- [x] `scripts/share-assets.mjs` + `scripts/share-card.json` (`pnpm share:assets`). The script screenshots the running game
  at 1440×810@2x and composes the 1200×630 card from that screenshot plus themed copy. It writes the card as a JPEG (about 100 kB) and
  renders the icons from `favicon.svg`: 180 px apple-touch, 192 and 512 px, and a 512 px maskable icon.
- [x] `apps/web/public/site.webmanifest` (standalone, theme and background colours, all icons).
- [x] Added root `netlify.toml` and `vercel.json` publishing `apps/web/dist`.
- [x] README "Sharing and SEO" section; two decision-log entries.

## 5. Known Limitations

- Previews show an image only once the site is deployed with a known origin. Localhost links cannot unfurl.
- `og-image.jpg` is a committed snapshot. Regenerate it after visible UI changes.
- Platforms cache previews. After changing the card, re-scrape with the Facebook Sharing Debugger (WhatsApp follows the same cache).
- English only; there are no `hreflang` alternates.
